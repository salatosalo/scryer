# SCRYER 🔮

> **Персональный AI-тренер и анализатор ошибок для League of Legends.**  
> Scryer берет официальный таймлайн матча Riot Games, находит моменты, где ты потерял темп или закинул игру, и дает четкие советы, как побеждать в следующем матче.

---

## ⚡ Для чего этот проект

Большинство сайтов со статистикой (OP.GG, U.GG) показывают только сухие цифры: KDA, урон и CS. Они не объясняют, **почему** ты проиграл, имея счёт 8/2, или **когда именно** игра пошла под откос.

**Scryer разбирает поминутный контекст матча:**
* Показывает, дрался ли ты на спайках предметов или бегал с 2000+ непотраченного золота в кармане.
* Отслеживает смерти без вардов и отданные баунти прямо перед появлением Дракона или Барона.
* Анализирует расстановку игроков в тимфайтах и ошибки в позиционировании.

---

## 🎮 Главные фичи

* **🎯 Честная оценка игры (S / A / B / C / D и баллы 0–100):**  
  Оценка ставится не за красивый KDA, а за реальный вклад в победу — контроль волн, давление на карте, участие в ключевых драках и макро-решения.

* **❌ Топ ошибок матча с точными минутами:**  
  Прямые таймкоды фейлов: плохой тайминг бэка, заход в туман войны без вижна, нереализованный сплитпуш или потеря темпа в лейте.

* **🗺️ Интерактивная миникарта Ущелья:**  
  Посекундная анимация перемещения всех 10 чемпионов, маркеры убийств, взятия вышек и эпических монстров.

* **⚔️ Разбор драфта и сборки предметов:**  
  Оценка матчапа на линии, синергии с командой, оптимальности рун и порядка покупки айтемов против вражеского сетапа.

* **💡 2–3 правила на следующую игру:**  
  Никакой воды — только практические выводы, которые можно сразу применить в следующем лобби для поднятия винрейта.

## 🚀 Запуск проекта

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env.local` (скопируйте из `.env.local.example`) и укажите ваш [Riot API Key](https://developer.riotgames.com/) и ключ [Google Gemini](https://aistudio.google.com/apikey) или [Groq](https://console.groq.com/keys).
3. Запустите сайт:
   ```bash
   npm run dev
   ```
   *(Или на Windows просто запустите `start.bat` двойным кликом).*

Откройте в браузере: **http://localhost:3000**
